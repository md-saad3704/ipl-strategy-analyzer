# IPL Strategy Analyzer

An advanced cricket analytics platform that analyzes IPL captain decision-making under pressure using real ball-by-ball match data.

## Features

- Pressure moment detection
- Captain strategy analysis
- Bowling change analytics
- Spinner vs pacer tactics
- Interactive match simulations
- React analytics dashboard

## Tech Stack

### Backend
- Python
- Flask
- Pandas
- NumPy

### Frontend
- React.js
- Recharts
- Axios

## Data Source

Cricsheet IPL JSON Data

https://cricsheet.org/
